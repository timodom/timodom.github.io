# CLAUDE.md: vault index (Memory layer)

Put this at the root of your Obsidian vault. Claude Code reads it automatically.
Keep it under ~40 lines. It is a map, not a notebook: say WHERE things are.

## Who I am
- Name, role, what I'm optimising for this quarter (1 line each).

## Where things live
- Business: `01 Business/`: strategy in `Strategy.md`, offers in `Offers/`
- Clients: `02 Clients/<Client>/`: one folder per client, `_Status.md` inside each
- Career: `03 Career/`: `Pipeline.md` is the job/interview tracker
- Trading: `04 Trading/`: rules in `Rules.md`, journal in `Journal/YYYY-MM-DD.md`
- Personal: `05 Personal/`
- Daily notes & digests: `Daily/`

## Conventions
- Tasks: `- [ ] text 📅 YYYY-MM-DD`; people as `@Name`
- Link notes with [[wikilinks]]
- New notes go in the matching area folder, never the vault root

## Rules for Claude
- Read this file first; open only the files it points to.
- Never delete files. Never move files without asking.
- Ask before editing anything in `04 Trading/Rules.md`.
- The MAPS dashboard reads this vault; it refreshes itself after your edits.
